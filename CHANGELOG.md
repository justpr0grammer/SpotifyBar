# Changelog

## 0.5.0

- Added SoundCloud and browser media sessions alongside Spotify.
- Added Auto / Spotify / SoundCloud player selection in the tray menu.
- Added tests for active player selection and browser support.
- Updated the interface to show the selected media source.

## 0.4.0

- Added an animated vinyl record with album artwork or a yellow fallback label.
- Animation pauses when playback stops.

## 0.3.0

- Changed the global shortcut to Alt+X.

## 0.2.0

- Added a monotonic playback clock with gradual synchronization.
- Added tests for stale snapshots, pause, resume, seeks and track changes.

## 0.1.0

- Rebuilt the Python prototype as a C# / Windows Forms application.
- Added the dark interface, Windows audio mixer, tray controls and UA / EN languages.
